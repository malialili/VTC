## 🎯 Conseils pour les images

### 1. Optimisation SEO
- Utilisez des noms de fichiers descriptifs : `berline-noire-vtc-bordeaux.jpg` au lieu de `IMG_1234.jpg`
- Ajoutez des balises `alt` dans le HTML : `<img src="berline.jpg" alt="Berline VTC noire à Bordeaux">`
- Compressez les images pour améliorer le temps de chargement

### 2. Accessibilité
- Fournissez toujours une description `alt` pour les images
- Pour les images décoratives, utilisez `alt=""`
- Assurez-vous que le texte reste lisible sans les images

### 3. Performance
- Utilisez le format WebP pour une meilleure compression (si supporté)
- Servez des images adaptées à la taille de l'écran (srcset)
- Utilisez le lazy loading pour les images hors écran

### 4. Droits d'auteur
- Utilisez uniquement des images que vous avez créées ou pour lesquelles vous avez les droits
- Respectez les licences (Creative Commons, etc.)
- Évitez les images protégées par des droits d'auteur

## 🔄 Mise à jour des images

Pour mettre à jour une image :
1. Créez la nouvelle image avec les bonnes dimensions
2. Optimisez-la (compression, format)
3. Donnez-lui le même nom de fichier
4. Remplacez l'ancienne image par la nouvelle
5. Videz le cache du navigateur pour vérifier

## 💡 Astuces

1. **Utilisez des images WebP** : Ce format offre une meilleure compression que JPEG ou PNG
2. **Servez des images adaptatives** : Utilisez `srcset` pour servir des images de différentes tailles
3. **Utilisez le lazy loading** : Pour améliorer les performances
4. **Ajoutez des placeholders** : Pour une meilleure expérience utilisateur
5. **Testez sur différents appareils** : Pour vous assurer que les images s'affichent correctement
